# Sorting Visualizer 🎨📊

A simple and interactive web-based Sorting Algorithm Visualizer that helps you understand how different sorting algorithms work through colorful animations.

## 🚀 Features

- Visualize popular sorting algorithms in action
- Step-by-step sorting animation
- Adjustable speed and array size
- Clean and intuitive UI

  ## 🧠 Algorithms Implemented
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

  ## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
